i# Smart Campus Connect - Frontend Client

Frontend client for **Smart Campus Connect**, developed by **SPA**.

## Tech Stack
- React 19
- Vite
- Tailwind CSS
- React Router v7
- Lucide React & React Icons
- React Toastify

## Getting Started
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
